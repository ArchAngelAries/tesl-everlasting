# Credits — TESL: Everlasting

TESL: Everlasting is made by **ArchAngelAries**, built with AI coding assistants (Claude by Anthropic, and Codex by OpenAI
in earlier phases).

## The original game
- ***The Elder Scrolls: Legends*** — developed by **Dire Wolf Digital** and later **Sparkypants Studios**, published by
  **Bethesda Softworks** (ZeniMax Media). All game content belongs to them. Thank you for a wonderful game.

## Data and research
- **crow2cr0w** — [tesl-offline](https://github.com/crow2cr0w/tesl-offline): published the original card rule graphs that
  TESL: Everlasting uses for about 1,000 cards (GPL-3.0 repository; see `NOTICE.md`).
- **The UESP editors** — [UESP Legends pages](https://en.uesp.net/wiki/Legends:Legends): card, puzzle, story, level,
  arena and title facts, and the store pack pictures (CC BY-SA 2.5).
- **The Elder Scrolls: Legends Fandom wiki editors** — cross-checks of card and story details.
- **TESL-Reborn** — a TESL-Reborn developer kindly gave the owner access to a working reference installation, which let
  us check rules and behaviour against the real game. TESL-Reborn is a separate project and not affiliated with us.
- Fan remakes used only as behaviour references (no code or data copied):
  [FlinnBurgess/elder-scrolls-legends](https://github.com/FlinnBurgess/elder-scrolls-legends) and the TESL Browser
  Project ([tesl.online](https://tesl.online)).
