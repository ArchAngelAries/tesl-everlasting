# The F10 menu

Press **F10** anywhere in the game to open or close TESL: Everlasting's menu. Settings are saved for your computer.

## Display and graphics (offline and online)

| Option | Choices | Notes |
|---|---|---|
| Display / Window | game's choice, windowed, maximized, fullscreen | The window can be resized by dragging its edges. Maximized fills the screen above the taskbar. |
| Quality preset | Low, Medium, High, Ultra, custom | Ultra = High + 8× MSAA, sharper and longer shadows, more lights, soft particles. Changing any single option makes it "custom". |
| Frame cap | 60, 120, 144, unlimited | The original game was capped at 60 fps. |
| VSync | on / off | |
| Anti-aliasing | 2×, 4×, 8× MSAA (never off: some story scenes draw a black table without it) | |
| Texture filtering | off up to 16× anisotropic | |
| Full-res textures | on / off | |
| FPS counter | on / off | |

## Launch mode

- **Switch to online mode** (offline launch, shown only when TESL-Reborn is installed) and **Switch to offline mode**
  (online launch). The choice is saved in `.offline-user-data/launch.json` and the game restarts.

## Practice and modes (offline)

- **Practice mode:** choose a mod game mode (made with TESL Forge) or *ordinary practice*. Then start **Play > Practice**.
- **Practice opponent:** choose a specific opponent, or the game's choice.
- **Mod opponents and decks in random Practice:** let random Practice opponents use mod decks too.

## Stories (offline)

- **Stories cost gold:** off by default (all story acts free). Turn it on to buy acts with gold, as in the original.

## Cheats — offline against the in-game AI only

These change your local profile. They never exist in an online launch, and a client that tries to use offline code against
a remote match is force-closed.

| Section | Cheats |
|---|---|
| Currency | +1000 gold, +500 gems, +5 tickets |
| Collection | Unlock all cards (full playsets), Unlock all premade decks, Free deck building (any number of copies of a card; decks up to 100 cards; offline only) |
| Current match (your turn) | +5 magicka now, +1 max magicka, Draw a card, Heal 10, Win the match, Trigger Beast Form (your werewolves change form), Restore a rune / Restore opponent's rune (also heals just above that rune), Heal opponent 10, return a card you pick from your discard pile to your hand |

## Support

The menu ends with links to support the project (Ko-fi and Patreon). They open in your browser.
